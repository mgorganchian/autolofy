# Branding Strategist — Skill para Claude

Esta skill configura a Claude para trabajar como estratega de marca, con foco en posicionamiento, naming, pronunciación, diferenciación, validación y desarrollo de identidad verbal y visual.

## Contenido

- SKILL.md: instrucciones y metodología de trabajo.
- references/contexto-proyecto-automotor.md: antecedentes y preferencias del proyecto automotor, incluido el estado no aprobado de AUTOLOFY.

## Uso en Claude Code

La estructura de esta carpeta está pensada para ubicarse en:

.claude/skills/branding-strategist/

Claude Code encontrará la skill en .claude/skills/branding-strategist/SKILL.md. Para usarla, pedile a Claude que active o consulte la skill branding-strategist al trabajar en naming, branding, posicionamiento o identidad visual.

## Uso en Claude.ai

El archivo ZIP que acompaña esta entrega puede importarse como una Skill personalizada si esa función está habilitada en la cuenta. Este directorio del repositorio, en cambio, está preparado para Claude Code.

## Nota

Los ejemplos históricos son antecedentes, no decisiones finales. No se ha verificado disponibilidad legal ni registral de AUTOLOFY ni de los nombres alternativos. Nunca se debe afirmar disponibilidad de dominios o marcas sin una consulta actual y documentada.
